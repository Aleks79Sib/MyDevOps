**Журнал изменений**   
1. Устраните проблему с загрузкой старой версии прошивки UEFI, когда безопасная загрузка отключена.
2. Исправьте последнюю проблему с загрузкой Kicksecure. (#3651)
3. Исправлена проблема, из-за которой опция `VTOY_WIN_UEFI_RES_LOCK` сбрасывалась при входе в VentoyPlugson.
4. Обновление языков.

**Внимание**   
Ventoy использует новый центр сертификации безопасной загрузки UEFI, начиная с версии 1.1.14, поэтому вам необходимо зарегистрировать новый ключ для первой загрузки.  
Если вы хотите удалить ключ, использованный в старой версии, см.:
[https://www.ventoy.net/en/doc_delete_key.html](https://www.ventoy.net/en/doc_delete_key.html)
