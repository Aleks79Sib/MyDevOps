# Создание мультизагрузочной флэшки Ventoy

Что такое Ventoy
Ventoy - это инструмент с открытым исходным кодом для создания загрузочного USB-накопителя для файлов ISO/WIM/IMG/VHD(x)/EFI.
С Ventoy вам не нужно форматировать диск снова и снова, просто перетаскивать файлы на USB-накопитель и загружать их напрямую.

Ознакомиться подробно можно о Ventoy [здесь](https://www.ventoy.net/en/index.html)

Посмотреть как выглядит при мультизагрузке [флэшка](https://www.ventoy.net/en/screenshot.html)
