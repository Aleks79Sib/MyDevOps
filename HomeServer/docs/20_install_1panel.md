# 📘 Инструкция по установке и первичной настройке 1Panel на Ubuntu Server 26.04 LTS

Эта инструкция составлена на основе нашего диалога и учитывает все типичные вопросы, возникшие в процессе установки и настройки панели.

## 1. Подготовка сервера
Перед установкой убедитесь, что ваша система обновлена:

```bash
sudo apt update && sudo apt upgrade -y
```

Убедитесь, что у вас есть root-доступ или возможность выполнять команды через sudo. Установка 1Panel не требует предварительной установки Docker — скрипт установит его автоматически.

## 2. Установка 1Panel
Выполните в терминале следующую команду:

```bash
curl -sSL https://resource.fit2cloud.com/1panel/package/quick_start.sh -o quick_start.sh && sudo bash quick_start.sh
```
В процессе установки:

- Скрипт проверит и при необходимости установит Docker и docker-compose.

- Вас попросят выбрать директорию установки (по умолчанию предлагается /opt).
- Рекомендация: если у вас есть отдельный большой раздел (например, /data), укажите его, чтобы избежать переполнения системного раздела в будущем.

- Пример: при запросе введите /data/1panel.

- Скрипт сгенерирует и выведет на экран:

  - URL для доступа к панели (содержит порт и путь безопасного входа).

  - Имя пользователя (admin) и пароль.

  - Сохраните эти данные в надёжном месте!

После завершения установки вы увидите примерно такое сообщение:

```text
Congratulations! 1Panel has been successfully installed.
面板地址: http://<IP>:<порт>/<случайная_строка>
账号: admin
密码: <сгенерированный_пароль>
```

## 3. Первый вход и проверка

Откройте браузер и перейдите по полученному URL. Если вы используете домен и настроили Cloudflare Tunnel, путь безопасности всё равно нужно указывать в URL (например, https://panel.mydomain.me/случайная_строка).
На этом этапе соединение будет по HTTP — это нормально, мы настроим HTTPS позже.

## 4. Настройка безопасности (обязательно)

### 4.1. Смена пароля администратора

Войдите в панель, затем в разделе Настройки → Безопасность измените пароль.
Также можно сделать это через терминал:

```bash
sudo 1pctl update password
```

### 4.2. Управление путём безопасного входа (Safety Entrance)

По умолчанию включён случайный путь, который нужно указывать в адресной строке. Вы можете:

- Оставить как есть — это безопасно.

- Изменить на свой (например, mypanel):

```bash
sudo 1pctl set entrance mypanel
```
Теперь адрес будет https://<ваш_домен>/mypanel.

- Отключить (если не нужен):

```bash
sudo 1pctl reset entrance
```
**Важно**: если вы используете Cloudflare Tunnel, не прописывайте путь безопасности в настройках туннеля — укажите только IP и порт (без пути). Путь передаётся в URL браузера.

## 5. Настройка HTTPS

### Вариант А — через встроенный интерфейс 1Panel (если есть домен)

- Зайдите в панель и перейдите в Сайты → Настройки вашего сайта.

- Во вкладке HTTPS включите «Автоматически перенаправлять HTTP на HTTPS».

- Импортируйте или создайте SSL-сертификат (поддерживается автоматическое получение через Let’s Encrypt, если домен правильно направлен на IP сервера).

- Сохраните настройки.

### Вариант Б — через Cloudflare Tunnel (если нет публичного IP или хотите дополнительную защиту)

- Зарегистрируйтесь в Cloudflare и добавьте свой домен.

- В разделе Zero Trust → Networks → Tunnels создайте новый туннель.

- Установите cloudflared на сервер (скопируйте команду из интерфейса Cloudflare).

- В настройках туннеля укажите Public Hostname:

  - Поддомен, который будет вести на панель (например, panel).

  - В поле URL укажите http://localhost:41537 (или IP вашего сервера и порт 1Panel) — без пути безопасности!

- Сохраните туннель. Теперь доступ будет по https://panel.ваш-домен.ру/путь_безопасности.

*Примечание*: в настройках туннеля не добавляйте путь к URL-адресу источника — это вызовет ошибку, подобную той, что мы разбирали. Путь безопасности всегда указывается в браузере.

## 6. Завершающие шаги

### 6.1. Удаление установочных файлов

После успешной установки вы можете удалить архив и распакованную папку установщика, чтобы освободить место:

```bash
rm -rf ~/quick_start.sh ~/1panel-v1.10.34-lts-linux-amd64*
```

**Не удаляйте рабочую папку**, которую вы указали при установке (например, /opt/1panel или /data/1panel) — в ней хранятся все данные панели.

### 6.2. Проверка работоспособности

Перезагрузите сервер и убедитесь, что панель автоматически запускается:

```bash
sudo systemctl status 1panel
```

Если всё работает, вы увидите статус active (running).

## 7. Дополнительные полезные команды
Действие	                                            Команда
Посмотреть информацию о пользователе и пути входа	`sudo 1pctl user-info`
Сбросить пароль (если забыли)	                    `sudo 1pctl reset password`
Обновить 1Panel до последней версии	                `sudo 1pctl update`
Включить/отключить HTTPS через терминал (если есть сертификаты)	`sudo 1pctl enable https / disable`

## 8. Рекомендации по безопасности

- Включите двухфакторную аутентификацию (если поддерживается в будущих версиях).

- Регулярно обновляйте 1Panel и Docker.

- Используйте сложные пароли и меняйте путь безопасного входа, если используете стандартный.

- Рассмотрите возможность использования Cloudflare Access для дополнительной аутентификации перед доступом к панели.
