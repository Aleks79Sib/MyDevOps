# 🆘 Решение проблем

---

## 1. Не хватает оперативной памяти

```bash
# Проверить использование
free -h

# Решение:
# 1. Остановить редко используемые сервисы
docker-compose stop [service_name]

# 2. Использовать AI-модель поменьше (3B вместо 7B)

# 3. Добавить файл подкачки
sudo fallocate -l 4G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile

# 4. Сделать подкачку постоянной (добавить в /etc/fstab)
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
```

## 2. Диск переполнен

```bash
# Проверить использование
df -h

# Решение:
# 1. Очистить Docker
docker system prune -a

# 2. Удалить старые AI-модели
docker exec -it ollama ollama rm [model_name]

# 3. Очистить логи systemd
sudo journalctl --vacuum-time=7d

# 4. Очистить кэш apt
sudo apt clean
sudo apt autoremove -y

# 5. Найти самые большие файлы
sudo du -sh /* 2>/dev/null | sort -rh | head -10
```

## 3. Сервис не запускается

```bash
# 1. Проверить логи
docker-compose logs [service_name]

# 2. Проверить порты (не заняты ли)
sudo ss -tlnp | grep [PORT]

# 3. Перезапустить сервис
docker-compose restart [service_name]

# 4. Обновить образ
docker-compose pull [service_name]
docker-compose up -d [service_name]

# 5. Проверить, что контейнер запущен
docker ps -a | grep [service_name]
docker inspect [service_name] | grep -A 5 "State"
```

## 6. Работа с правами доступа файлы и папки

The three digits represent:                                                                       
 - First digit: owner permissions                                                                  
 - Second digit: group permissions                                                                 
 - Third digit: others (everyone else) permissions                                                 
                                                                                                   
 Each digit is a sum of:                                                                           
 - 4 = read (r)                                                                                    
 - 2 = write (w)                                                                                   
 - 1 = execute (x)                                                                                 
 - 0 = no permissions                                                                              
                                                                                                   
 So:                                                                                               
 - 6 = 4+2 = read + write                                                                          
 - 7 = 4+2+1 = read + write + execute                                                              
 - 5 = 4+1 = read + execute                                                                        
 - 4 = 4 = read only                                                                               
 - 0 = no permissions                                                                              
                                                                                                   
 666 = owner(rw), group(rw), others(rw)  
chmod права (Unix):                                                                               
                                                                                                   
 Каждая цифра — это сумма прав для одной категории:                                                
                                                                                                   
 ┌───────┬─────────┬───────────────────────────────────────┐                                       
 │ Цифра │ Бинарно │ Права                                 │                                       
 ├───────┼─────────┼───────────────────────────────────────┤                                       
 │ 0     │ 000     │ нет прав ---                          │                                       
 ├───────┼─────────┼───────────────────────────────────────┤                                       
 │ 1     │ 001     │ только выполнение --x                 │                                       
 ├───────┼─────────┼───────────────────────────────────────┤                                       
 │ 2     │ 010     │ только запись -w-                     │                                       
 ├───────┼─────────┼───────────────────────────────────────┤                                       
 │ 3     │ 011     │ запись + выполнение -wx               │                                       
 ├───────┼─────────┼───────────────────────────────────────┤                                       
 │ 4     │ 100     │ только чтение r--                     │                                       
 ├───────┼─────────┼───────────────────────────────────────┤                                       
 │ 5     │ 101     │ чтение + выполнение r-x               │                                       
 ├───────┼─────────┼───────────────────────────────────────┤                                       
 │ 6     │ 110     │ чтение + запись rw-                   │                                       
 ├───────┼─────────┼───────────────────────────────────────┤                                       
 │ 7     │ 111     │ всё: чтение + запись + выполнение rwx │                                       
 └───────┴─────────┴───────────────────────────────────────┘                                       
                                                                                                   
 Три цифры — три категории:                                                                        
                                                                                                   
 ```                                                                                               
   chmod 644 file                                                                                  
            ││└── others (все остальные) → 4 = r--                                                 
            │└── group (группа)         → 4 = r--                                                  
            └── owner (владелец)        → 6 = rw-                                                  
 ```                                                                                               
                                                                                                   
 Для меня (agent_pi — не владелец, не в группе node) нужно третья цифра = 6 (чтение + запись):     
                                                                                                   
 ┌──────────────┬──────────┬────────┬───────────────────────┐                                      
 │ Команда      │ Владелец │ Группа │ Остальные             │                                      
 ├──────────────┼──────────┼────────┼───────────────────────┤                                      
 │ chmod 644    │ rw-      │ r--    │ r-- ❌ не могу писать │                                      
 ├──────────────┼──────────┼────────┼───────────────────────┤                                      
 │ chmod 664    │ rw-      │ rw-    │ r-- ❌                │                                      
 ├──────────────┼──────────┼────────┼───────────────────────┤                                      
 │ chmod 666 ✅ │ rw-      │ rw-    │ rw- ✅ могу писать    │                                      
 └──────────────┴──────────┴────────┴───────────────────────┘   


 права на папку и на файлы — это разные вещи.                                                 
                                                                                                   
 Для файла 666 = можно читать и писать.                                                            
                                                                                                   
 Для папки (чтобы создавать новые файлы внутри):                                                   
 - 6 (rw-) = можно список файлов (ls) и создавать/удалять файлы                                    
 - 7 (rwx) = можно заходить в папку (cd) + создавать/удалять                                       
                                                                                                   
 Так что если хотите, чтобы я мог создавать новые файлы в src/ — нужно:                            
                                                                                                   
 ```bash                                                                                           
   chmod 777 /workspace/projects/DO7_Docker_Compose_ID_1219717-1/src/                              
 ```                                                                                               
                                                                                                   
 Но 777 — это небезопасно. Лучший вариант — добавить меня в группу node:                           
                                                                                                   
 ```bash                                                                                           
   usermod -aG node agent_pi                                                                       
   chmod 775 /workspace/projects/DO7_Docker_Compose_ID_1219717-1/src/                              
 ```                                                                                               
                                                                                                   
 Тогда:                                                                                            
                                                                                                   
 ┌────────────────────────────┬────────────────┬────────────────────────┐                          
 │ Кто                        │ Права на папку │ Может создавать файлы? │                          
 ├────────────────────────────┼────────────────┼────────────────────────┤                          
 │ Владелец (node)            │ rwx (7)        │ ✅                     │                          
 ├────────────────────────────┼────────────────┼────────────────────────┤                          
 │ Группа (node)              │ rwx (7)        │ ✅                     │                          
 ├────────────────────────────┼────────────────┼────────────────────────┤                          
 │ Я (agent_pi в группе node) │ rwx (7)        │ ✅                     │                          
 ├────────────────────────────┼────────────────┼────────────────────────┤                          
 │ Остальные                  │ r-x (5)        │ ❌ только читать       │                          
 └────────────────────────────┴────────────────┴────────────────────────┘
