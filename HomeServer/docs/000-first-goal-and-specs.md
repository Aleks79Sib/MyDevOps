# 🏠 Домашний сервер "Всё в одном" на базе ноутбука packard bell EASYNOTE_TS11-HR-006RU


## 🎯 Цель проекта
Превратить старый ноутбук (из не поддерживаемой WINDOWS 10) в универсальный домашний сервер со следующими сервисами:
- 💬 **Собственный мессенджер** для семьи (Nextcloud Talk)
- 📹 **Видеозвонки** (Nextcloud Talk)
- 🏠 **Умный дом** (Home Assistant) — в разработке
- 🗄️ **Своя база данных** (PostgreSQL)
- 🔐 **Менеджер паролей** (Vaultwarden)
- 🤖 **Автоматизации** (n8n)
- 📁 **Файловое хранилище** (Samba/Nextcloud)
- 🎬 **Медиасервер** (Jellyfin) — в разработке
- 🤖 **ИИ ассистент** — Agent_Pi (через API Deepseek)

---

## 📦 Технические характеристики
- **Ноутбук:** packard bell EASYNOTE_TS11-HR-006RU
- **Процессор:** Intel Core i5-2410M (2 ядра, 4 потока, 2.3-2.9 GHz)
- **Оперативная память:** 16 ГБ DDR3
- **Диск 1:** ADATA SU650 100 ГБ SSD (система + БД)
- **Диск 2:** DEXP 1 ТБ SSD (данные + модели AI)
- **Сеть:** Gigabit Ethernet + Wi-Fi
- **BIOS:** AMI BIOS v3.5 (только Legacy, без Secure Boot)
