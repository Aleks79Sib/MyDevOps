# 🛠️ Установка и настройка Ubuntu Server 24.04.04


### 🖥️ Шаг 1: Установка Ubuntu Server 24.04.04
#### Загрузка с флешки:
1. Вставить флешку, перезагрузить
2. Выбрать: **"Try or Install Ubuntu Server"**
- Идет процесс установки


#### Настройки установки:
1. **Язык и раскладка:**
  - **Язык**: English
  - **Раскладка**: Russian (придется пройти индефикацию клавиатуры и выбрать способ переключения раскладки)
  
  **⚠️** Если вы не видите раскладки, нажмите **"Ctrl+Alt+T"**, чтобы открыть терминал.


2. **Установка**:
- **Choose the base for the installation**:
  - [X] Ubuntu Server  ← **ЭТОТ ВАРИАНТ!**

  - ( ) Ubuntu Server (minimized)

  - [ ] Search for third-party drivers → **НЕ СТАВИТЬ ГАЛОЧКУ!**

*Примечание:* 🔧 Почему стандартная:
- Есть все необходимые драйверы для твоего ноутбука
- Будет man, help, документация
- Меньше проблем с совместимостью
- Можно потом удалить лишнее, если нужно



3. **Сеть:**
- **Network connections**:
  - Выбрать Ethernet интерфейс (enp0s3/eth0)
  - IPv4 Method: DHCP

- **Proxy address: (оставить ПУСТЫМ!)**
- **Mirror address (зеркало для пакетов) — оставить по умолчанию**


4. **Хранилище (ВАЖНО!):**

- **[ ] Use an entire disk- ОСТАВЛЯЕМ ПУСТЫМ - для ручной настройки** или выбрать для автоматической настройки

- **[X] Custom storage layout**

- 🛠 Шаг 1: Удалить старые разделы (если данные не нужны)
**‼️ Внимание: Это сотрёт все данные на дисках!**

  - Выберите диск ADATA_SU650... (111 ГБ) → нажмите на него → выберите "Reformat" или "Delete partition" для каждого существующего раздела (1, 2, 3).

  - Выберите диск DEXP_SSD... (953 ГБ) → удалите существующий NTFS-раздел.

*После удаления все диски будут отображаться как "FREE SPACE"*.

- 🛠 Шаг 2: Создать новые разделы на первом диске (ADATA 111 ГБ)
 - Нажмите на "FREE SPACE" под диском ADATA → "Create partition".

Создавайте разделы по плану:

- **Storage_1 (Диск 1)**: (/dev/sda — ADATA 111.8 ГБ):
  - sda1: 1 MB (BIOS boot) — создаётся автоматически
  - sda2: /boot — 1 GB (Ext4)
  - sda3: swap — 4 GB
  - sda4: / — 35 GB (Ext4) ← корневая
  - sda5: /var/lib/postgresql — 71.8 GB (Ext4) ← для БД

- 🛠 Шаг 3: Создать разделы на втором диске (DEXP 1 ТБ)
Нажмите на "FREE SPACE" под диском DEXP → "Create partition".

Создайте:


- **Storage_2 (Диск 2)**: (/dev/sdb — DEXP 596.2 ГБ):
  - sdb1: /var/lib/docker — 150 GB (Ext4) ← КОНТЕЙНЕРЫ
  - sdb2: /data — 446.2 GB (Ext4) ← ВСЁ ХРАНИЛИЩЕ

- 🛠 Шаг 4: Настроить точки монтирования
Для каждого созданного раздела (кроме swap) при создании выберите:

  - Format: ✓
 - Mount point: укажите соответствующую точку (/, /data и т.д.)

- 🛠 Шаг 5: Проверить и завершить

После создания разделов откройте терминал (Alt+F2) и выполните проверку:

```bash
lsblk
```

*Должно получиться примерно так:*

```text
sda      8:0    0 111.8G  0 disk 
├─sda1   8:1    0     1M  0 part 
├─sda2   8:2    0     1G  0 part /boot
├─sda3   8:3    0     4G  0 part [SWAP]
├─sda4   8:4    0    35G  0 part /
└─sda5   8:5    0  71.8G  0 part /var/lib/postgresql
sdb      8:16   0 596.2G  0 disk 
├─sdb1   8:17   0   150G  0 part /var/lib/docker
└─sdb2   8:18   0 446.2G  0 part /data
```

Если видите похожую картину — всё сделано правильно.
